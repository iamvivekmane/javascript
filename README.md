A deep dive into core JavaScript concepts — from the basics of hoisting and scope to closures, higher-order functions, and asynchronous JavaScript. Each day builds on the last toward a solid understanding of how JS actually works under the hood.

## 🛠️ Concepts Covered

- Execution context, hoisting & the call stack
- Scope, closures & the lexical environment
- `let`, `const`, and the temporal dead zone
- Higher-order functions, `map`, `filter`, `reduce`
- Callbacks, callback hell, and the shift to Promises
- Promises: creation, chaining, error handling, `Promise.all`/`allSettled`/`race`/`any`
- Async/await and try-catch error handling
- The event loop, microtasks & macrotasks
- The JS engine & V8 architecture
- The `this` keyword across different contexts
